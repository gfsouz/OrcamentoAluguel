# Orçamento de Aluguel

Sistema para gerar orçamentos de aluguel com cálculo automático e exportação em CSV.

## Como usar

```bash
python orcamento.py
```

## Funcionalidades

- Cálculo de aluguel por tipo de imóvel
- Parcelamento de contrato (1-5 meses)
- Exportação em CSV com projeção anual
- Interface interativa

## Requisitos

- Python 3.6+
